# e-Portfolio — Jeanne Faure-Soulet

Site statique (HTML/CSS/JS), bilingue FR/EN, thème clair/sombre.

- **Contenu à modifier** : `assets/js/content.js` (textes, parcours, sections, vidéo).
- **CV** : `assets/cv/` (PDF). La source du CV anglais est `cv/CV_EN.html`.
- **Photo** : `assets/img/photo.jpg`.
- **Vidéo** : mettre un lien YouTube dans `pitchVideo.youtube` (dans `content.js`) ; le bloc vidéo apparaît automatiquement.

Mise en ligne : Settings → Pages → Deploy from a branch → `main` / `(root)`.
